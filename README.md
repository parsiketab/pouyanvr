# پویان اکسپو — نمایشگاه مجازی کارگزاری پویان

نسخهٔ وب (چندفایلی) برای انتشار روی GitHub Pages. یک `index.html` برای دسکتاپ و موبایل؛ نوع دستگاه خودکار تشخیص داده می‌شود.

## ساختار
```
index.html          صفحهٔ ورود (ساختار HTML و موشن ورود)
css/style.css       همهٔ ظاهر: رنگ‌ها، پنل‌ها، دکمه‌ها
js/config.js        لینک ثبت‌نام و فهرست تصاویر و مدل‌ها
js/app.js           برنامهٔ اصلی (ساخته‌شده؛ برای تغییر، سورس را ویرایش و دوباره بساز)
img/                تصاویر (WebP)
models/             مدل‌های سه‌بعدی و نقشهٔ نور
fonts/              فونت وزیرمتن
.nojekyll           لازم برای GitHub Pages؛ پاکش نکن
```

## انتشار روی GitHub Pages
1. در GitHub یک مخزن تازه بساز (مثلاً `pouyan-expo`) و آن را **Public** کن.
2. **Add file → Upload files** را بزن و **محتوای همین پوشه** را (نه خود پوشه را) بکش و رها کن، بعد **Commit changes**.
3. **Settings → Pages**: در Source گزینهٔ **Deploy from a branch**، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و Save کن.
4. بعد از یکی دو دقیقه سایت روی `https://<نام‌کاربری>.github.io/pouyan-expo/` بالا می‌آید.

> فایل `.nojekyll` در مک و ویندوز مخفی است. اگر در آپلود جا ماند، در GitHub با **Add file → Create new file** فایلی خالی به همین نام بساز.

## نکته‌ها
- `index.html` را مستقیم از روی کامپیوتر (دابل‌کلیک) باز نکن؛ مرورگر اجازهٔ خواندن مدل‌ها را از روی دیسک نمی‌دهد. روی GitHub Pages یا یک سرور محلی درست کار می‌کند
  (`python -m http.server` در همین پوشه، بعد `http://localhost:8000`).
- برای دامنهٔ اختصاصی (مثلاً `expo.pouyanbroker.ir`) در Settings → Pages بخش Custom domain را پر کن و رکورد CNAME را در DNS بگذار.
